چطور حکم‌ها محاسبه می‌شوند؟

۱ · ساختار ICT

سوییگ‌های ۳ کندلی استخراج می‌شوند. اگر هم سقف‌ها و هم کف‌ها بالا بروند (HH/HL) ساختار صعودی است؛ اگر هر دو پایین بیایند (LH/LL) نزولی. وزن: ۳

۲ · ایچیموکو

قیمت نسبت به ابر: بالای ابر صعودی، داخل ابر خنثی، زیر ابر نزولی. وزن: ۲

۳ · چیدمان EMA

جایگاه قیمت نسبت به EMA 21، 50 و 200 — هر کدام یک امتیاز. وزن: ۲

۴ · RSI

زیر ۳۵ اشباع فروش (مثبت) و بالای ۶۵ اشباع خرید (منفی). وزن: ۱

۵ · مومنتوم

تغییر قیمت نسبت به ۵ روز پیش. بالای ۱.۵٪ مثبت، زیر منفی ۱.۵٪ منفی. وزن: ۱

۶ · موقعیت در رنج روز

اینکه قیمت در کدام بخش از دامنه‌ی روز بسته شده — بالای رنگ یا پایین رنگ. وزن: ۱

چرا حکم نسبی است؟ امتیاز خام هر کوین محاسبه و سپس کل ۱۰۰ کوین رتبه‌بندی می‌شوند؛ ۱۵٪ برتر BUY و ۱۵٪ ضعیف‌ترین SELL می‌گیرند. در بازار یک‌طرفه، حکم مطلق «۹۰ فروش» چیزی به شما نمی‌گوید — حکم نسبی می‌گوید در مقایسه با بقیه این کوین کجا ایستاده.

امتیاز خام روی هر کارت نمایش داده می‌شود تا خودتان بسنجید. اگر داده‌ی یک منبع قطع شود، وزن آن از مخرج کم می‌شود و تعداد ورودی‌های زنده روی کارت نمایش داده می‌شود.

سؤالات پرتکرار

این داشبورد چطور کار می‌کند؟

داده‌های کندل روزانه ۱۰۰ کوین برتر از TradingView گرفته می‌شود و سپس ساختار ICT، موقعیت ایچیموکو، چیدمان EMA، RSI و مومنتوم با وزن‌دهی ترکیب می‌شوند.

چند وقت یک‌بار به‌روزرسانی می‌شود؟

هر ساعت به‌صورت خودکار توسط GitHub Actions. آخرین به‌روزرسانی در بالای صفحه نمایش داده می‌شود.

قیمت‌ها از کجا می‌آیند؟

از TradingView. برای هر کوین چند صرافی به‌ترتیب امتحان می‌شود (Binance، Gate.io، MEXC، KuCoin، Bybit، OKX، Bitget، Coinbase) تا بیشترین پوشش بازار را بگیریم.

آیا سیگنال مالی است؟

خیر. ابزار تحلیل تکنیکال آموزشی است و توصیه مالی نیست.

هزینه‌ای دارد؟

کاملاً رایگان. بدون ثبت‌نام، بدون API key، بدون سرور مجازی.

ساخته‌شده با GitHub Pages + GitHub Actions — بدون سرور، بدون هزینه، بدون ردیابی.
