# داشبورد سیگنال ۱۰۰ کوین برتر

داشبورد تحلیل تکنیکال ارزهای دیجیتال — **بدون سرور، بدون هزینه، بدون API key**.

🔗 **https://apluscancode.github.io/crypto-signal-board/**

## چطور کار می‌کنه

```
CoinGecko top-250  →  فیلتر تا ۱۰۰ کوین معامله‌پذیر
        ↓
TradingView        →  کندل روزانه ۱۲۰ دوره برای هر کوین
                    →  fallback بین Binance / Gate.io / MEXC / KuCoin /
                       Bybit / OKX / Bitget / Coinbase
        ↓
signal_engine.py   →  ICT + الیوت + ایچیموکو + RSI + EMA + مومنتوم
        ↓
data/signals.json  →  داشبورد سمت کلاینت
```

## منطق حکم

| ورودی | وزن | منطق |
|-------|------|------|
| ساختار ICT | ۳ | HH/HL صعودی · LH/LL نزولی |
| ایچیموکو | ۲ | بالای ابر / داخل / زیر ابر |
| چیدمان EMA | ۲ | جایگاه نسبت به EMA 21، 50، 200 |
| RSI | ۱ | <۳۵ مثبت · >۶۵ منفی |
| مومنتوم | ۱ | تغییر ۵ روزه |
| موقعیت در رنج روز | ۱ | Close Location Value |

امتیاز خام محاسبه و **نسبت به کل ۱۰۰ کوین** رتبه‌بندی می‌شود؛
۱۵٪ برتر `BUY`، ۱۵٪ ضعیف‌ترین `SELL`، بقیه `HOLD`.

> **چرا نسبی؟** در بازار یک‌طرفه، حکم مطلق «۹۰ فروش» هیچ اطلاعاتی نمی‌دهد.
> حکم نسبی می‌گوید این کوین **در مقایسه با بقیه** کجا ایستاده.
> امتیاز خام روی هر کارت نمایش داده می‌شود.

## به‌روزرسانی

`.github/workflows/refresh.yml` هر ساعت (`:07` UTC) اجرا می‌شود:

1. `build_universe.py` — ۱۰۰ کوین برتر را از CoinGecko می‌گیرد
2. `fetch_candles.js` — کندل روزانه را از TradingView می‌گیرد
3. `signal_engine.py` — حکم‌ها را حساب می‌کند
4. commit + push → GitHub Pages خودکار redeploy می‌کند

## اجرای محلی

```bash
npm install @mathieuc/tradingview
python3 build_universe.py
node fetch_candles.js
python3 signal_engine.py
python3 -m http.server 8000
```

## داده و محدودیت‌ها

- منبع قیمت: **TradingView** (بدون کلید، بدون محدودیت اعتبار)
- فریم زمانی: روزانه (`D`)، ۱۲۰ کندل
- اگر یک صرافی قطع شود، صرافی بعدی در زنجیره امتحان می‌شود
- اگر داده‌ی یک ورودی قطع شود، وزن آن از مخرج کم می‌شود و
  تعداد ورودی‌های زنده (`inputs` / `total_inputs`) روی کارت نمایش داده می‌شود
